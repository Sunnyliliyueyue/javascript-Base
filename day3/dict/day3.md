1. AJAX
    优点：
    网页能够快速的将增量更新呈现在页面上，而不需要重新加载整个页面。使得程序能够更快的回应用户的操作
    实现原理：
    1. 创建Ajax对象
    2. 传入请求方式和请求地址
    3. 发送请求
    4. 获取服务器和客户端的响应数据

2. 跨域问题
   1. 同源策略：
        是浏览器最核心也是最基本的安全功能，如果缺少了同源策略，浏览器容易收到攻击
        同源：协议 域名 端口三者相同
        要求浏览器要求在解析Ajax请求时，需要浏览器路径与ajax请求的路径必须满足同源策略，只有满足才可以访问服务器
        默认可忽略的端口号：http->80     https->443
    2. 不需要解决的跨域
        1. 跨域资源嵌入
        2. 跨域写操作
    3.  跨域读操作（需要解决）

    4. 解决
        1. JSONP
        2. CORS（跨域资源共享）
        3. 代理服务器 
                |
        proxy: {
            '当前所需要匹配的路径':{
                target: '请求路径'
            }
        }
3. 面向对象
    三大特性：封装，继承，多态

    JS设计模式：
    原型、工厂、构造函数
    特点：原型：通过给构造函数的原型添加属性可以被实例所继承
          构造函数：通过new创建对象，类型是可以确定的，并且对象和构造函数间存在联系
          工厂：对象创建过程中封装函数里面，可以更好创建复杂逻辑
